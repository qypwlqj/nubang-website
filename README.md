# 努邦科技官网 · NUBANG

上海努邦科技有限公司官方网站 —— Next.js 16 + TypeScript + Tailwind CSS v4。

## 关于公司

上海努邦科技有限公司（Shanghai Nubang Technology Co., Ltd.）成立于 2012 年，
曾用名「上海努邦润滑新材料有限公司」，主营润滑油原料、添加剂与成品油，
并提供成品油定制服务；同时提供 AI 赋能的化学实验室整体解决方案（软件服务支持 + 实验室设备）。

- **润滑产品**：添加剂 / 原料 / 成品油 / 成品油定制
- **化学实验室解决方案**：软件服务支持（AI 油液监测、智能配方推荐等）+ 实验室设备
- **服务与支持**：成品油定制 & 实验室设备定制 / 7×24h 售后 / 专业原料技术指导

## 开发

```bash
npm install
npm run dev   # 默认 0.0.0.0:7100，可用 PORT 环境变量覆盖
npm run build
```

## 部署（Vercel）

仓库为零配置 Next.js 项目，在 Vercel 中 Import Git Repository 即可自动构建部署。

## 备注

- `lib/img/*.ts` 中的图片以 data URI 内联（MCP 通道仅支持文本传输的折衷方案）；
